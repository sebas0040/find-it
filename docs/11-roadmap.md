# Roadmap

- Autenticacion JWT.
- Busqueda geolocalizada.
- Mapa.
- Favoritos.
- Reviews.
- Perfil usuario.
- Perfil tienda.
- Inventario tienda.
- Seeds demo.

## Prioridades Tecnicas

- Endurecer permisos backend indicados en `API_QUICK_REFERENCE.md`.
- Revisar rutas legacy `/api/stores`, `/api/categories`.

- Agregar tests de integracion para inventario, favoritos, reviews y search.
- Mejorar configuracion por ambiente del frontend.
- Completar Dockerfile del frontend si se requiere despliegue containerizado.
